# プロバイオティＸ（開発中の実験台）

乳酸菌をテーマにした発酵ゲーム。XYZシリーズ第3作（麹菌Ｚ「変える」／酵母Ｙ「増やす」／乳酸菌Ｘ「守る」）。

**まだゲームではなく手触りの実験台です。** タイマー・スコア・負け筋・タイトルは未実装。

## 遊び方
なぞって桿菌（乳酸菌）を繋ぎ、腐敗菌を輪で囲んで封じる。

- 繋いだ本数 = 一度に溶かせる匹数（足りないと耐えられる）
- 酸を出した桿菌は消耗して暫く拾えない
- 酸の帯（軌跡）は1.5秒で尾から蒸発 → 大きく囲うには素早く回る
- 鎖が腐敗菌に触れると四散。散った菌は拾わないと餓死する

## 現在の状況：操作方式を比較中
スマホ実機で「ひと続きでなぞる」方式がストレスになったため、**動詞「つなぐ」を残したまま操作方式を作り直し中**。
`index.html` は各案へのメニューです。

## ファイル
- `index.html` — 各実験台へのメニュー（公開時の入口）
- `feel-tap.html` — **案A** タップで順に繋ぐ（指が一瞬しか触れない＝遮蔽が消える）
- `feel-splice.html` — **案B** 短いストロークの継ぎ足し（指を離しても鎖が残る）
- `feel-seal.html` — 従来のひと続きでなぞる方式（比較用・機能は最も揃っている）
- `feel-chain.html` — 核の手触りだけを切り出した最初の実験
- `versions/` — 過去版（`index_v1_rejected.html` は却下した初回試作）
