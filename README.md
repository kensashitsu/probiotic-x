# プロバイオティＸ（開発中の実験台）

乳酸菌をテーマにした発酵ゲーム。XYZシリーズ第3作（麹菌Ｚ「変える」／酵母Ｙ「増やす」／乳酸菌Ｘ「守る」）。

**まだゲームではなく手触りの実験台です。** タイマー・スコア・負け筋・タイトルは未実装。

## 遊び方
なぞって桿菌（乳酸菌）を繋ぎ、腐敗菌を輪で囲んで封じる。

- 繋いだ本数 = 一度に溶かせる匹数（足りないと耐えられる）
- 酸を出した桿菌は消耗して暫く拾えない
- 酸の帯（軌跡）は1.5秒で尾から蒸発 → 大きく囲うには素早く回る
- 鎖が腐敗菌に触れると四散。散った菌は拾わないと餓死する

## 現在の状況：核の手触りを活かした別ルールを2案試作中
「なぞって磁石のように吸い付く」動作自体はユーザー評で気持ち良いと確定。
一方で**狭い画面で点の敵を避けられずぶつかる**のがストレスの正体だったため、
**衝突する敵が存在しない構造**の2案を作った（腐敗を点ではなく面／マスにした）。

## 本命の設計（2026-07-27）
**乳酸は殺菌ではなく静菌**という正しい生物学から、腐敗菌は「触れても無害・増えることだけが脅威」に。
これで**ぶつかる概念が消えたまま「囲む」操作が復活**した（ストレスの原因は囲む操作ではなく、
点の敵に触れると全損するルールだった）。

## ファイル
- `index.html` — 各実験台へのメニュー（公開時の入口）
- `feel-contain.html` — **本命** 囲って増殖を抑える（食品を限定しない・静菌の原理そのもの）
- `feel-wall.html` — **案1** 酸の壁を築く（腐敗は全方位から迫る面。集めた桿菌は離した場所に定着して壁になる）
- `feel-turf.html` — **案3** 陣取り（マス目。腐敗は隣へ広がる。塗り返して押し合う）
- `feel-chain.html` — 核の手触りだけを切り出した実験（気持ち良いと確認済み）
- `feel-tap.html` — 却下：タップで順に繋ぐ
- `feel-splice.html` — 却下：短いストロークの継ぎ足し
- `feel-seal.html` — 却下：ひと続きでなぞって囲む（点の敵を避ける方式）
- `versions/` — 過去版

## 却下した案
- **オフセット操作**（操作点を指より上に置く）＝違和感が強く、手の遮蔽より悪化した
- **タップで繋ぐ／継ぎ足し**＝どちらも求める手触りに届かなかった
- **点の敵を避けながら囲む**＝狭い画面で避けられずストレスの本体だった
